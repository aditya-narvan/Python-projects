# Python Projects

Small Python programs built while learning CS50P.

## Programs
- calculator.py — basic calculator with 4 operations
- guess_game.py — number guessing game with tries counter
- even_odd.py — even/odd checker with input validation
- password_validator.py — password strength checker with regex
- grade_calculator.py — student grade calculator for 5 subjects
- temperature_converter.py — converts between Celsius, Fahrenheit and Kelvin
